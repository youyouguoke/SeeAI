Agent 页刻意停在机制层：目标、规划、工具、观察、决策与重规划。它不讲哪家的 Agent 框架更好，不做多 Agent 编排，也不做工具市场——这些属于未来的话题。这一页只回答一个问题：一个 AI 系统如何不靠人逐步指挥，就把一件事从头做到尾。
